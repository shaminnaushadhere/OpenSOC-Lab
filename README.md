# OpenSOC Lab

OpenSOC Lab is a reusable SOC training environment focused on hands-on detection, telemetry, investigation, and MITRE ATT&CK mapping.

## Initial Goals

- Collect Windows telemetry with Sysmon
- Forward telemetry into Wazuh
- Build custom detection rules
- Run repeatable SOC scenarios
- Perform analyst-style investigations
- Track detection coverage with MITRE ATT&CK
